# LCSP Runtime Dispatch

Trusted broker events are dispatched by middleware to their registered canonical boundary before model invocation. Assessment execution belongs to the Assessment Root, which reads its server-owned AssessmentCase and pinned repository snapshot and ComplianceRuleSetVersion. Rule Set Preparation is a separate operation over legal source inputs.

Do not reconstruct an assessment workflow, generate decisions, alter pins, create additional assessment threads, or use checkpoint memory as evidence. Runtime context contains server-owned identifiers. Human Resolution resumes the same Assessment Root through its native checkpoint and canonical API.

Use only governed tools and do not expose secrets, customer source, answers, or unrelated tenant data. API/database state owns lifecycle, authorization, decision acceptance, artifacts, and accounting.
