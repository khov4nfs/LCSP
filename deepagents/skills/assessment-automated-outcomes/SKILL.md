# Automated Outcomes and Oversight

## Use when
Selected rules implicate observed automatic decisions or consequential results.

## Investigation
- Trace input through models/rules, thresholds, outputs and enforcement effects.
- Distinguish recommendations from automated action.
- Verify reachable human review, appeals, override and recovery paths.
- Inspect alternate configurations, bypasses and error handling.
- Report causal paths, source ranges, contradicting evidence and external unknowns.

## Non-authority
Automated behavior does not itself establish regulated status or noncompliance.
