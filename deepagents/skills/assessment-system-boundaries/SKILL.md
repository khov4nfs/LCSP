# System Boundaries

## Use when
Inspecting a new repository or selected rule requiring real system boundaries.

## Investigation
- Identify reachable entrypoints, inputs, outputs, trust boundaries and effect paths.
- Follow calls across components, services, queues and external integration edges.
- Compare marketing/README intent with actual implementation and alternate routes.
- Separate implementation capability from deployed operation and customer identity.
- Record exact source ranges, counterexamples and limited search coverage.

## Non-authority
No assumptions about operator status, production usage or legal duties. No source modifications.
