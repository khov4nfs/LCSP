# Model and Inference Integrity

## Use when
Relevant ML inference is observed and selected criteria require understanding it.

## Investigation
- Trace model loading, input preprocessing, sampling and output semantics.
- Compare local class labels to upstream taxonomy only if authoritative metadata exists.
- Examine confidence filtering, aggregation, thresholds and downstream decisions.
- Check model variants and actual consumer paths, not labels or README alone.
- Separate verified source discrepancies from speculative reliability risks.

## Non-authority
Never invent model metadata, deployment weights, validation statistics or legal duties.
