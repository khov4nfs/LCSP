# Data Lifecycle

## Use when
Selected obligations concern data collection, access, transfer, retention or deletion.

## Investigation
- Trace intake, processing, persistence/cache/logging, network transfers and deletion.
- Verify related access controls and effective source checks if material.
- Inspect alternative sinks and failure routes; compare local versus external state.
- Distinguish repository source claims from authenticated operational facts.
- Record bounded coverage, contradictions and facts requiring a customer answer.

## Non-authority
Missing corporate documents in Git cannot prove their nonexistence outside Git.
