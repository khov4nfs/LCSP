- (direction) Implement Prompt 2 ASM-23 and ASM-ADMIN-01..04 with CUSTOMER owner-only content reads and ADMIN metadata-only reads.
- (capability) CAP-1 CUSTOMER reads only owned assessment content; success requires owner-scoped persistence predicates and unchanged customer projections.
- (capability) CAP-2 ADMIN lists and retrieves safe operational metadata without owner impersonation or content hydration.
- (capability) CAP-3 Provenance and customer content-rich runtime SSE reject ADMIN at the RBAC boundary.
- (constraint) Authorization remains RBAC-only with CUSTOMER and ADMIN; no PBAC or organization model is introduced.
- (constraint) ADMIN metadata permission never grants mutation or customer-content permission.
- (decision) ADMIN metadata fields are assessment_id, owner_id, name, lifecycle_state, execution_state, created_at, updated_at, plus response correlation metadata.
- (event) Coherence validation passed: three capabilities have explicit intent and testable success, constraints and non-goals are explicit.
- (event) Preservation validation passed: every Prompt 2 acceptance rule is represented; no wrapper-only requirement was dropped.
