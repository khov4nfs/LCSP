# LCSP release notes — 2026-10-14

**Release line:** current `develop` candidate. LCSP has no product SemVer tag or GitHub Release, and these notes do not confirm a production deployment.

## What changed

- APX routes select Anthropic or OpenAI protocol explicitly while keeping APX as the canonical provider and credential authority. The configured fallback chain is APX, Google GenAI, then Inception. ([PR #381](https://github.com/khov4nfs/LCSP/pull/381), [PR #382](https://github.com/khov4nfs/LCSP/pull/382))
- Rule Set Preparation now has explicit administrator start, retry, and cancellation controls; agent terminal activity is validated and projected against persisted state. ([PR #374](https://github.com/khov4nfs/LCSP/pull/374), [PR #377](https://github.com/khov4nfs/LCSP/pull/377), [PR #378](https://github.com/khov4nfs/LCSP/pull/378))
- APX allowance exhaustion retires the affected credential slot; transient rate limits use cooldown before provider fallback. ([PR #381](https://github.com/khov4nfs/LCSP/pull/381))

## Migration note

The release documentation candidate includes [`20261013132644_re_generate_db`](../../apps/api/prisma/migrations/20261013132644_re_generate_db/migration.sql). It removes the unused `WizardProfile` table/type and reconciles schema constraints and indexes. The table drop can remove stored rows; verify retention requirements before any production application. Production application has not been verified.
